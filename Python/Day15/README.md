## Project: Student Dictionary CRUD Manager

A console-based Python program that stores and manages student information using a dictionary.

### Student Information

- Name
- Age
- Course

### Features

- View student information
- Update student information
- Remove student information
- Exit the program
- Validate user input

## Program Structure

The project was divided into separate functions:

- `main()`
- `text_validator()`
- `number_validator()`
- `get_name()`
- `get_age()`
- `get_course()`
- `create_student()`
- `display_menu()`
- `view_information()`
- `update_information()`
- `remove_information()`

## CRUD Implementation

| Operation | Function |
|---|---|
| Create | `create_student()` |
| Read | `view_information()` |
| Update | `update_information()` |
| Delete | `remove_information()` |
